# Like / Comment / Share a post

As a user, I want to like, comment and share posts so I can interact with content.

Acceptance criteria:

- Backend: POST /make-server-7c20c7e0/posts/:postId/like toggles like. Comments stored under post comments key. Shares create a new post referencing original.
- UI: Buttons for like, comment, share. Comments thread UI and optimistic updates.

Estimate: 5 pts
